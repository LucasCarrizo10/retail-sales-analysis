# Capturas del dashboard

Capturas de las tres páginas del informe realizado en Power BI Desktop.

- `1- Resumen comercial.png`: indicadores principales, ingresos por categoría y evolución mensual.
- `2- Productos y clientes.png`: análisis de productos y comportamiento de clientes.
- `3- Canales y medios de pagos.png`: comparación de canales de venta y medios de pago.

El archivo `.pbix` conserva las visualizaciones interactivas originales. Las capturas son evidencia visual estática.
